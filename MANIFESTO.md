# Mindcap Manifesto

## Declaration

We believe capture important digital context with provenance and integrity so it can be reviewed, restored, and safely transformed into knowledge is worth doing carefully, openly, and with respect for the people affected by the system.

## We stand for

- Capture before interpretation: make the commitment visible in behavior, not only prose.
- Provider behavior stays isolated: make the commitment visible in behavior, not only prose.
- Archives are immutable: make the commitment visible in behavior, not only prose.
- Verification precedes deletion: make the commitment visible in behavior, not only prose.
- Secrets never enter artifacts: make the commitment visible in behavior, not only prose.

## We reject

- concealed authority and irreversible surprise;
- lock-in disguised as convenience;
- claims of certainty without evidence;
- automation that erases human context;
- architecture that centralizes ownership merely because it is easier today.

## Commitment

We will keep Mindcap independently understandable, honestly incomplete when evidence is missing, and open to revision when better evidence or lived experience contradicts current assumptions.

## Evidence and uncertainty

- **Observed:** The repository README and checked-in implementation establish an extensible Python CLI for capturing source material, preserving verified archives, and preparing canonical knowledge inputs.
- **Decided for this draft:** The repository owns the bounded concern described here and participates through versioned contracts.
- **Proposed:** Target systems and later roadmap phases remain proposals until accepted and implemented.
- **Open question:** Which parts of this draft should become active in the first independently versioned release?
